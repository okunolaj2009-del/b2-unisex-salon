# B2 Unisex Salon website

Static site. Keep this structure exactly:

```
index.html
images/   (logo, gallery photos, video cover pictures)
videos/   (all videos)
README.md
```

## Put it on GitHub Pages
1. Create a new GitHub repository and upload `index.html`, the `images` folder and the `videos` folder (drag them into Add file > Upload files).
2. Repo Settings > Pages > Deploy from branch > `main` / root.
3. Your site goes live at `https://<username>.github.io/<repo>/`.

Do not rename folders or files: the page finds each one by its exact path.
